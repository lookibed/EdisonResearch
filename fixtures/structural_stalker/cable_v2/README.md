# cable_v2: явный контракт без изменения старого опыта

`cable_v1` и его первый прогон сохранены. Вторая версия исправляет доступ к данным,
а не подгоняет ответ исследователя под ручной граф.

* Справочные ссылки `material:*` теперь читаются. Они возвращают уже опубликованный
  эталон, без новых сведений о составе образца.
* Публично объявлено: `observe` работает в холодных состояниях; импульсы и чтение
  документов — также в горячем. Разрешённые переходы состояний перечислены явно.
* Для возврата к 20 °C заданы отдельные записи `*-R`; повтор того же источника в том
  же состоянии не становится независимым опытом.
* Каждая попытка получает `call_id`, включая отказ доступа. `record_id` остаётся
  идентификатором записи источника. Ошибка доступа не является измерением вещества.

Бюджет сохранён: 18 действий до события, ещё 3 после. Геометрия и значения основных
18 записей из v1 сохранены. Ожидания скопированы **побайтно** из ручной разметки v1;
исторический `fixture_id` внутри файла ожиданий намеренно оставлен.

`manifest.json` фиксирует SHA-256 данных. Сборка всех трёх новых стендов:
`python scripts/build_structural_fixtures.py`. Скрипт не меняет v1.

Исследователь читает только `public/start.json`; доверенный диспетчер дополнительно
читает `private/responses.json`. `private/expectations.json` применяется при разборе
после запуска, в контекст модели не поступает.

Два заранее составленных контроля используют тот же интерфейс и бюджет:

* `../homogeneous_v2`: нет разрешённых внутренних переходов контраста; проверка,
  не воспроизводит ли модель привычные три слоя вопреки данным.
* `../shifted_v2`: другая геометрия, одинаковый точечный материал в различимых
  геометрических областях. Проверка отделения материала от физической части.

Названия директорий и тексты ожиданий не передаются исследователю. Контрольные
стенды имеют непрозрачные публичные ID `R42` и `K81`, без подсказки о геометрии.

Это синтетическая таблица, без реального оптического или химического симулятора.
Документы намеренно могут расходиться с наблюдениями; такое расхождение требуется
сохранить, а не решать угадыванием скрытого химического названия.
